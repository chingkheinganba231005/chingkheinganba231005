## Research

**[Pretrained Eyes on an Old Script](https://github.com/chingkheinganba231005/Handwritten-Meitei-Mayek-Recognition)**  
*Manuscript under peer review at Scientific Reports (Springer Nature).*  
Fine-tuned and ensembled pretrained convolutional networks for 55-class handwritten Meitei Mayek recognition. The final ensemble achieved **98.12% accuracy** on the official TUMMHCD test set, compared with the previously reported best result of 97.08%. Includes reproducible experiments, ablations, and a browser-based demo.

**[Beyond Isolated Characters](https://github.com/chingkheinganba231005/meitei-mayek-word-recognition)**  
*Manuscript under peer review at The Visual Computer (Springer Nature).*  
Developed a segmentation-free handwritten-word recognizer using synthetic word generation and a ConvNeXt–BiLSTM–CTC pipeline. Achieved **2.96% character error rate** on a small real-handwriting test set of 100 words from one writer.
